# Backup Vault

![License](https://img.shields.io/github/license/Sdursun/BackupVault)
![Platform](https://img.shields.io/badge/platform-AmigaOS%203.x-orange)
![Architecture](https://img.shields.io/badge/architecture-m68k-blue)

A backup / restore / sync / verify utility for AmigaOS 3.x, with a MUI
graphical front end (**BackupVault**), a matching command-line tool
(**Backup**), and two headless companion tools still under active
development (**BackupVaultDaemon**, **BackupVaultWebDaemon**).

This repository distributes the ready-to-run release package (compiled
binaries + documentation). Source code is kept private.

## Contents

- `BackupVault` - the MUI GUI application
- `Backup` - command-line equivalent
- `BackupVaultDaemon` - headless scheduler (runs jobs unattended)
- `BackupVaultWebDaemon` - headless web front end
- `BackupVault.readme` - full feature list, setup, and usage (Aminet-style)
- `BackupVault.guide` - the same content as an AmigaGuide manual

## Getting started

See [`BackupVault.readme`](BackupVault.readme) for installation, the
full feature list, and known limitations, or open
[`BackupVault.guide`](BackupVault.guide) on an Amiga for the same
content in AmigaGuide form.
